# 2026秋季路线：校内、实习、项目三线合一

## 定位

你目前是“见过Python语法，但还不能独立完成小程序”。本学期采用T型路线：

- Java是近期实习主线，和学校Java课同步，未来做账号、训练记录和数据库服务。
- Python是项目特色线，未来做姿态估计、模型推理和生物力学计算。
- C、数据结构、计算机系统优先服务校内课程，同时直接帮助笔试。

## 正常周时间：18小时

- 数据结构/C上机6小时
- LeetCode 4小时
- Java与作业4小时
- MuscleScope项目3小时
- Git、复盘、英文资料1小时

周一数据结构+简单题；周二Java+小练习；周三Python项目；周四C指针+简单题；周五Java+错题；周六项目2小时+算法2题；周日测试、提交、周复盘并留半天休息。期中期末前两周将项目降至1小时。

## 16周目标

1. Python函数、文件、JSON、模块、异常、测试；完成角度分析器。
2. C指针与顺序表；Python列表/字典；多关节JSON输出。
3. C结构体、malloc/free和链表；Java类与封装；PoseFrame数据对象。
4. 栈队列；Java继承/接口/异常；深蹲四阶段状态机；完成M0。
5. 哈希与复杂度；Java集合；将动作阈值移入配置文件。
6. 二叉树与递归；Java泛型；设计Session→Set→Rep数据结构。
7. HTTP、请求响应和状态码；设计分析API的JSON契约。
8. SQLBolt练习；表、主外键、索引；设计三张训练记录表。
9. Python虚拟环境和OpenCV；读取视频、FPS和逐帧循环。
10. MediaPipe/RTMPose；保存关键点；拒绝低置信度帧。
11. 移动平均、中值滤波、速度；平滑角度并进行深蹲计数。
12. FastAPI路由、响应、错误与测试；将纯函数包装成API。
13. Spring Boot最小服务：Controller、Service、DTO；不引入微服务。
14. MySQL索引、事务；训练记录持久化；解释索引取舍。
15. 建立约30段获授权测试视频；报告计数准确率、角度MAE、拒绝率。
16. Docker/Linux最小部署；准备3/10/30分钟项目讲解并开始投递。

## 算法顺序

数组/链表 → 栈队列/哈希 → 二叉树/二分 → 堆/回溯 → 动态规划入门 → 图基础。

寒假前目标80—120道有效复盘题，其中30—40道中等；2027暑假前150—200道。有效复盘指能隔天重写、说明复杂度、边界和曾经的错误。

## 资料（每类只选一个主资源）

- Python：继续黑马的文件、模块、JSON、异常部分；书用《Python编程：从入门到实践》第3版。
- C：《C Primer Plus》按学校章节查指针、数组、字符串、结构体、动态内存。
- 数据结构：学校课为主；B站“浙江大学 数据结构 陈越、何钦铭”补充。
- 算法：代码随想录题单+LeetCode，不并行刷多个题单。
- Java：《Head First Java》第3版；B站黑马或尚硅谷只选一套并与学校同步。
- 系统：学校课+CSAPP对应章节；需要时看CMU 15-213中文字幕。
- 网络：《图解HTTP》后接《计算机网络：自顶向下方法》。
- 数据库：SQLBolt动手，再读《MySQL是怎样运行的》。
- CV：OpenCV-Python、MediaPipe官方文档。
- 生物力学：OpenCap论文、Pose2Sim和OpenSim官方教程，M1之后开始。
