## 目标与现实判断

- 冲刺目标：2027年1—2月开始投递日常/寒假实习。
- 主目标：2027年3—6月参加暑期实习招聘，最迟2027年暑期获得一段开发相关实习。
- 岗位主线：Java后端/AI应用工程；不把纯算法研究岗作为唯一目标。

以当前基础，暑期目标来得及，但前提是持续执行、尽早投递，并接受第一段实习不一定是顶级大厂。项目不能替代算法、Java和校内课程。

## 每周约18小时课外预算

项目8小时，算法/数据结构5小时，Java3小时，系统/网络/复盘2小时。学校作业和上机临近时优先校内任务；期中、期末前两周项目降到2—3小时，只维护连续性。

### 默认周安排

- 周一（2小时）：数据结构/LeetCode 1小时；Java学校内容复写1小时。
- 周二（1.5小时）：项目新知识30分钟；亲手实现60分钟。
- 周三（2小时）：C/数据结构上机1.5小时；错题复写30分钟。
- 周四（1.5小时）：项目小功能、异常与测试。
- 周五（2小时）：Java 1小时；计算机系统/网络1小时。
- 周六（5小时）：项目3小时；算法2小时。
- 周日（4小时）：项目2小时；算法1小时；测试、Git、周复盘1小时。

不要为了补时长熬夜。某天中断时移动任务，不把两天内容挤进一天。

## 阶段A：基础闭环（2026-09-13至10-11）

项目：

- 完成文件、JSON、模块、异常、命令行、测试。
- 完成关节角度分析器、深蹲四阶段状态机。
- 能指出每个函数和测试所在文件，讲清输入输出与异常。
- M0结束后不再以“抄短函数”为主要学习方式，转向小功能交付。

算法/学校：

- 数组、链表、栈、队列、哈希、二分。
- C指针、结构体、动态内存与调试。
- Java类、对象、继承、接口、异常、集合入门。

验收：全仓库测试真实运行通过；闭卷完成一个JSON命令行程序；有效算法题20—30道。

## 阶段B：单机位可演示M1（2026-10-12至12-27）

项目：

- Python虚拟环境、NumPy最小必要部分、OpenCV读取视频。
- 接入MediaPipe作为第一版关键点模型，不训练模型。
- 角度时序滤波、深蹲阶段、计数、置信度拒绝。
- FastAPI提供上传、任务结果和错误响应。
- 收集30—50段获授权短视频，按人拆分测试。
- 记录计数准确率、角度误差、拒绝率和P95处理时间。
- 一个最小演示界面；视频不提交GitHub。

算法/学校：

- 二叉树、堆、回溯、滑动窗口、动态规划入门。
- Java集合、泛型、IO、JUnit、线程概念。
- HTTP/TCP、进程线程和内存基础随校内课程学习。

验收：别人按README可运行；演示成功和失败样本；指标可由脚本复现；累计有效算法题60—90道。

## 阶段C：后端产品化M2（2026-12-28至2027-03-07）

项目：

- Spring Boot：Controller、Service、DTO、校验和全局异常。
- PostgreSQL：用户、训练、分析任务、结果元数据；关键SQL自己写。
- Java调用Python分析服务。
- 视频采用异步任务：提交后返回task_id，查询状态与结果。
- 实现超时、失败状态和幂等；先用数据库完成，确有瓶颈再引入Redis。
- Docker Compose运行Java、Python和PostgreSQL。
- 5—10位真实体验者；记录失败率和反馈。
- 部署公开演示或录制完整可复现演示。

求职：

- 2027年1月准备一页简历并开始投递，不等M2全部结束。
- 复习Java集合/JVM基础、MySQL/PostgreSQL索引事务、Redis常用结构、HTTP/TCP、OS。
- 累计有效算法题100—130道，开始Hot100高频复刷。
- 每周看2份目标岗位面经，只整理真实高频和自己不会的题。

验收：完整请求链路、数据库设计、异常恢复、部署说明和至少两项选型实验。达到这里已经是合格且有特色的实习项目。

## 阶段D：面试增强（2027-03-08至05-16）

优先顺序：

1. 修复真实用户和压力测试发现的问题。
2. 补接口测试、日志、指标、索引前后对比。
3. 对MediaPipe/RTMPose或同步/异步方案做一项真实选型实验。
4. 完成3分钟、10分钟、30分钟项目讲解。
5. 只有前四项达标才实现情感教练Agent Lite。

Agent Lite范围：

- 输入只能是结构化动作结果、训练历史和用户文本。
- 工具只保留动作知识查询、训练记录查询、建议生成。
- 疼痛、低置信度和高风险表达走明确安全规则。
- 有最大步骤、超时、成本记录和100条最小评测集。
- Agent关闭时系统仍返回规则模板报告，核心产品完整可用。

算法目标：累计150—180道且至少完成两轮高频复刷。持续投递、模拟面试和复盘。

## 学习资源和使用方式

- Python：不再从头刷长课；遇到文件、模块、测试、类型标注时看黑马对应小节和《Python编程：从入门到实践》。
- 数据结构：学校课为主，B站浙大陈越/何钦铭补不懂章节。
- 算法：前期代码随想录建立模块，后期Hot100/Codetop按目标公司复刷。
- Java：学校课 +《Head First Java》第3版；黑马或尚硅谷只选一套按需看。
- 系统：学校课 + CSAPP对应章节，不在本学期强行通读。
- 网络：《图解HTTP》入门，再按需读《计算机网络：自顶向下方法》。
- 数据库：SQLBolt动手；随后《MySQL是怎样运行的》，项目使用PostgreSQL时比较两者差异。
- CV：OpenCV-Python、MediaPipe官方文档。
- 生物力学：M1之后读OpenCap论文、Pose2Sim和OpenSim文档。

每次学习循环：先说明项目需求和输入输出 → 最多30分钟资料 → 60—120分钟独立实现 → 测试/失败样例 → Git提交 → 口头复述。视频看完不算完成。

## 面试就绪门槛

在简历写项目之前，至少满足：

- 能从接口定位到Java/Python文件和数据库表。
- 能现场修改一个阈值、字段或异常分支并重新测试。
- 有2个以上真实选型、2个以上难点及解决过程。
- 至少3项量化指标可以复现。
- README能让别人启动。
- 能区分自己代码、AI辅助代码和开源组件。
- 没有把规划功能写成已经实现。
