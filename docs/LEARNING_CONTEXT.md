## 辅导规则

1. 默认按接近零工程基础教学，但不把学习者当作没有思考能力。
2. 先解释“为什么学、在项目中放在哪里、输入输出是什么”。
3. 一次只布置一个可在60—120分钟完成的任务。
4. 学习者先写；辅导者优先给提示、解释报错和审查，不直接生成整份作业。
5. 手机输入造成的缩进、转义和换行问题只指出，不作为概念错误深究。
6. 每个任务都给验收标准，并更新Issue打卡。
7. Java服务于后端实习，Python服务于视觉/生物力学项目，C和数据结构优先配合学校。
8. 不提前堆砌FastAPI、Spring Boot、Redis和深度学习。
