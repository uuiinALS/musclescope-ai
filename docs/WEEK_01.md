# 第1周：从“看过Python”到“能独立完成小程序”

## 本周唯一目标

在不复制参考实现的情况下，完成：

```text
angle_input.json
      ↓
读取与校验
      ↓
计算三个点形成的夹角
      ↓
终端显示结果
      ↓
result.json
      ↓
unittest自动验证
```

总投入约12—14小时。学校作业多时，每天最少完成“保底任务”。

## 第1天：确认语法不是只会看（90分钟）

课程：

- 回看黑马Python中函数、参数、返回值对应内容，最多30分钟。
- 阅读《Python编程：从入门到实践》中函数章节的相关小节。

必须手写：

1. `add(a, b)`
2. `maximum(numbers)`，不使用内置 `max`
3. `distance(x1, y1, x2, y2)`
4. 写3次函数调用并打印返回值

保底任务：完成前两题。

验收：

- 能解释参数、返回值和局部变量。
- 输入空列表时，能主动说明应该返回什么或抛什么错误。
- 将练习提交为 `feat: finish day 1 function exercises`。

## 第2天：文件和with（90分钟）

课程：

- 黑马Python“文件操作”对应章节，最多35分钟。
- 亲手运行 `open`、`read`、`write`。

必须手写：

1. 创建一个文本文件，写入三行关节名称。
2. 读取文件并逐行打印，去掉换行符。
3. 尝试读取不存在的文件，观察错误信息。
4. 用 `try/except FileNotFoundError` 输出中文提示。

保底任务：完成读取和异常提示。

验收：

- 能解释为什么使用 `with open(...) as file`。
- 知道读取和写入模式不同。
- 不捕获笼统的 `Exception`。

## 第3天：JSON和字典（90分钟）

课程：

- 黑马Python“JSON”对应章节。
- Python标准库文档只查 `json.load` 和 `json.dump` 示例。

必须手写：

1. 读取 `examples/angle_input.json`。
2. 打印三个点的x、y。
3. 将 `{"angle_degrees": 90.0}` 写到新文件。
4. 修改JSON使其缺少 `vertex`，观察并处理 `KeyError`。

验收：

- 能说清JSON对象、Python字典和文件之间的区别。
- 不把文件路径写死成自己电脑的绝对路径。

## 第4天：模块、导入和数据类（100分钟）

课程：

- 黑马Python“模块与包”对应章节。
- 阅读仓库中的 `geometry.py`，但先不修改。

必须手写：

1. 在 `exercises/week01_tasks.py` 完成 `parse_point`。
2. 从另一个文件导入它。
3. 创建两个 `Point2D` 对象并打印。
4. 故意写错模块名，阅读完整报错，从最后一行向上定位。

验收：

- 能解释 `if __name__ == "__main__"` 的用途。
- 能区分模块、包、函数和类。

## 第5天：角度计算（120分钟）

只补需要的数学：

- 二维向量。
- 点积。
- 向量长度。
- `cos(theta) = dot(a,b)/(|a||b|)`。
- `acos`与弧度转角度。

必须手写：

1. 在纸上计算 `(1,0)` 与 `(0,1)` 的夹角。
2. 完成练习文件中的 `calculate_angle`。
3. 验证90°、180°和约45°。
4. 两个关键点重合时抛出 `ValueError`。

验收：

- 不看代码能解释为什么需要三个点。
- 能解释浮点误差为什么可能让余弦略超出 `[-1,1]`。
- 不追求背公式，但能根据公式重新写出代码。

## 第6天：测试和调试（150分钟）

课程：

- 搜索并观看一个不超过30分钟的“Python unittest 入门”视频。
- 阅读仓库 `tests/test_geometry.py`。

必须完成：

1. 运行全部测试。
2. 故意把公式中的加号改成减号，确认测试失败。
3. 根据失败信息定位，再恢复代码。
4. 自己新增一个45°测试。
5. 为重合点新增异常测试。

验收：

- 能说明测试为什么不是“运行一次看起来没问题”。
- 能解释Arrange、Act、Assert。
- 截图不是验收；测试命令通过才是验收。

## 第7天：闭卷小项目和复盘（180分钟）

先关闭教程和参考答案，用一个新文件从零完成：

1. 从命令行参数接收输入和输出文件名。
2. 读取JSON。
3. 校验三个点。
4. 计算角度。
5. 输出到终端和JSON文件。
6. 对文件不存在、JSON错误、关键点重合给出提示。

最多独立尝试60分钟；之后可以查文档。不要直接问Codex要完整答案，只能问类似：

- “这个报错最后一行是什么意思？”
- “请只给我一个排查方向，不要写代码。”
- “请审查我的函数边界情况。”

最终验收：

- `python -m unittest discover -s tests -v` 全部通过。
- 能闭卷讲出从JSON输入到JSON输出的调用链。
- 能修改输入文件并预测输出。
- 写一篇不少于300字的周复盘。
- 给自己打分：独立完成80%以上才进入第2周；否则再花2天补弱点。

## 本周禁区

- 不安装OpenCV、MediaPipe、FastAPI。
- 不学习Spring Boot、Redis或深度学习。
- 不让AI一次生成完整作业。
- 不为了“项目看起来高级”跳过异常和测试。

第一周真正打牢，后面的视觉模型才不会变成无法解释的黑盒拼装。
